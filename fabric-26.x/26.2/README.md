# Fabric 26.2 Client

Install Minecraft **26.2**, Fabric Loader **0.20.1 or newer**, and Java **25 or newer**. Put both JARs below into this instance's `mods` folder.

- Simple Voice Chat 2.6.26 for Fabric 26.2: https://cdn.modrinth.com/data/9eGKb6K1/versions/s0wBn5Sf/voicechat-fabric-2.6.26%2B26.2.jar
- [Peecer Voice TCP client add-on (universal for 1.21.11 and 26.x)](../peecer-voice-tcp-client-universal/peecer-voice-tcp-client-1.0.0.jar)

All clients on one server must use the matching Simple Voice Chat Minecraft build and the TCP add-on. Press **V** to configure audio; use Groups to create an isolated password group. This folder provides direct JAR instructions; use the official voice JAR link above.
